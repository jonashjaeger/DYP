YOUR DATA

Keep it yours.

DYP works offline and does not send your journal to a server.

Export & back up

Save a copy of your journal. CSV works in spreadsheets and R/Python. JSON preserves the full data model and can be restored here.

Restore a backup

Import a DYP JSON backup. Sessions are merged by ID, not duplicated. Existing matching entries are left unchanged.

Privacy & offline use

Sessions are stored in your browser's on-device IndexedDB. GPS is optional and requested only when you tap the location button. Data may be lost if you clear website data or remove the app: keep regular JSON backups.

Checking local storage…

Install DYP

On iPhone, open your hosted DYP website in Safari, tap Share, then Add to Home Screen. Open the icon once while online so the offline cache is prepared.

The app must be hosted over HTTPS for offline support and GPS (GitHub Pages is suitable).

Delete all sessions

Irreversibly erase the journal stored on this device. Export a backup first.
